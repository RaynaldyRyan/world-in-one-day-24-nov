A newspaper-style image summing up the world's news of Tuesday 24 November 2026, drawn programmatically by main.ts (Node 22, standard library only, no network); one 1024x1024 PNG, fully deterministic; masthead + date, stat strip, 3 lead stories, 5 medium cards, 14 numbered world briefs with a world map, and a DATE CHECK strip labelling stories from other dates. Every main-area story verified against a live source as happening or first reported on 24 November 2026.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
